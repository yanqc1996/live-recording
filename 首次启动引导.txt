播录助手 首次启动引导
==========================

适用对象：
第一次安装并使用 播录助手 桌面版的用户。


一、安装软件
------------

macOS 用户：

1. 双击打开 播录助手 的 dmg 安装包。
2. 将 播录助手.app 拖入“应用程序”文件夹。
3. 第一次打开时，如果系统提示“无法验证开发者”：
   - 请右键点击 播录助手.app；
   - 选择“打开”；
   - 在弹窗中再次点击“打开”。

说明：
当前版本暂未做 Apple 开发者签名，所以第一次打开有安全提示是正常现象。



二、激活买断授权
----------------

1. 打开 播录助手。
2. 进入首页顶部的“软件授权”区域。
3. 复制“当前设备码”。
4. 将设备码发送给卖家。
5. 卖家会根据你的设备码生成专属买断授权码。
6. 收到授权码后，粘贴到“买断授权码”输入框。
7. 点击“激活授权”。

激活成功后，会显示：

买断授权已激活

注意：

- 授权码会绑定当前设备。
- A 电脑的授权码不能直接用于 B 电脑。
- 如果更换电脑、主板、系统迁移后设备码变化，请联系卖家处理换机授权。


三、登录抖音账号
----------------

1. 在“抖音账号”区域点击“登录抖音”。
2. 软件会打开一个抖音登录窗口。
3. 按页面提示扫码或完成登录。
4. 登录完成后，软件会自动同步本机登录状态。

说明：

- 不需要手动填写 Cookie。
- 登录状态只保存在你的本机。
- 如果后续提示登录失效，请重新登录。
- 弹幕发送能力受抖音网页端安全校验影响，可能需要点击“刷新发送凭证”。


四、添加主播
------------

推荐使用“主播库”统一管理。

1. 点击顶部“主播库”。
2. 输入主播名称，可选。
3. 粘贴主播主页地址、分享链接或直播间地址。
4. 点击“添加主播”。
5. 点击“解析直播间”。
6. 如果主播正在直播，软件会自动解析到直播间地址。

说明：

- 如果主播当前未开播，可能无法解析直播间地址。
- 如果你已经知道直播间地址，也可以手动填写直播间地址。


五、开始本地录制
----------------

1. 进入“主播库”。
2. 选择一个主播。
3. 点击“加入录制”。
4. 切换到“本地录制”。
5. 确认直播间已出现在列表中，并且处于启用状态。
6. 设置保存目录、画质、保存格式。
7. 点击“开始本地录制”。

录制完成后，视频会保存在本机目录中。

默认保存位置：

项目目录 / downloads

也可以在“录像保存目录”中自行选择保存位置。


六、直播互动与只听音频
----------------------

1. 点击顶部“直播互动”。
2. 选择直播间。
3. 点击“开始监听”查看实时弹幕。
4. 如果只想听声音，点击“获取音频源”。
5. 如需发送弹幕，请先确保抖音账号已登录。

注意：

- 直播音频来自直播源，网络波动或平台限制可能导致断开。
- 软件已内置自动重连机制。
- 弹幕发送能力可能受抖音安全字段影响，不保证所有账号和直播间都可发送。


七、作品拉取
------------

1. 点击顶部“作品拉取”。
2. 粘贴用户主页、分享链接或 sec_user_id。
3. 选择保存目录，留空则使用录制保存目录。
4. 点击“开始拉取作品”。

去重逻辑：

- 软件会记录已拉取过的作品 ID。
- 默认只拉取新增作品。
- 如果本地手动删除过某个旧作品，默认不会再次重复拉回。
- 勾选“强制扫描历史页”后，会重新扫描历史作品，但仍会跳过已记录作品 ID。


八、媒体库
----------

1. 点击顶部“媒体库”。
2. 点击“刷新”。
3. 软件会按主播聚合本地录制和作品文件。
4. 可以查看文件数量、大小、类型和最近更新时间。


九、百度网盘上传，可选
----------------------

如果你不需要上传，可以忽略此功能。

如果需要上传：

1. 在“本地录制”页找到“百度网盘上传”。
2. 勾选“启用上传能力”。
3. 首次使用时点击“检测授权”。
4. 按提示完成百度网盘授权。
5. 可选择“录制完成后自动上传”。

说明：

- 打包版已内置 bypy，不需要用户安装 Python。
- 百度网盘授权和上传稳定性受百度接口、网络和账号状态影响。


十、常见问题
------------

1. 打不开软件怎么办？

macOS 请使用右键“打开”，不要直接双击。


2. 提示“请先激活软件授权”怎么办？

说明当前设备还没有激活。请复制设备码发给卖家，获取授权码后激活。


3. 登录抖音后仍然不能发送弹幕怎么办？

请进入“直播互动”，选择直播间后点击“刷新发送凭证”。
如果仍然提示缺少安全字段，说明当前账号或页面暂时无法拿到发送弹幕所需字段。


4. 为什么主播主页有作品，但拉取为空？

可能原因包括：

- 抖音登录状态失效；
- 该主页需要登录后才能查看；
- 抖音接口风控；
- 用户作品属于合集、推荐或权限限制；
- 平台接口临时变化。

请先重新登录抖音，再尝试拉取。


5. 音频播放一卡一卡怎么办？

可能是直播源或网络波动。
软件会自动检测播放进度，如果长时间无进展会自动重连。
如果频繁卡顿，可以尝试切换画质或稍后重试。


十一、使用注意事项
------------------

- 本工具仅用于本地个人录制、素材整理和直播观察。
- 请勿用于批量搬运、侵权传播、违规营销或其他违反平台规则的用途。
- 请自行确认录制、下载、保存和使用内容的版权与授权。
- 第三方平台接口可能变化，部分功能可能随平台策略调整而失效或需要更新版本。
- 软件不提供抖音账号、不提供代登录、不提供 Cookie。
