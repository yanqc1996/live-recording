# 本机录音转文字

媒体库 → 本机录音转文字 → 选择已结束录制的文件 → 开始转写。

支持中文、英文及自动识别。结果可搜索，点击时间戳播放原音频对应位置；TXT 和 SRT 通过界面导出。模型识别可能出错，尤其是音乐、方言和多人重叠讲话；不提供说话人识别。

## 本机依赖

- FFmpeg：桌面运行时已提供。
- whisper.cpp CLI：当前 Mac 使用 Homebrew 安装，`brew install whisper-cpp`。应用也识别 PATH、`/opt/homebrew/bin/whisper-cli`、`/usr/local/bin/whisper-cli`。CLI 不随应用包分发，其他电脑需要自行安装。
- 多语言 base 模型：界面首次下载约 142 MiB，从 whisper.cpp 官方脚本使用的 Hugging Face 仓库获取，并校验固定 SHA-256。可以重试下载失败的模型。

仅模型下载联网，音视频及转写文本均保留本机。运行识别时使用本机 CLI，不调用云端转写接口。

## 资源与任务

单工作线程串行处理，每次提取最多 5 分钟音轨，识别限制 2 个 CPU 线程、不启用 GPU，并降低进程优先级。进度按完成的分段计算，不是精确剩余时间。分段边界的语句可能被截断，应复核。

拒绝正在录制、最近 60 秒更新或不在当前媒体目录中的文件。任务途中源文件变化时标记失败。取消会终止当前子进程并删除临时音轨；失败/取消后可重试。应用重启后未完成任务标记为可重试，不会悄悄重新占用资源。重试从头开始。

任务及结果存放在用户数据目录 `engine/transcriptions/`，模型也在这里。不会修改源音视频。转写成功后重复提交相同文件版本与语言会复用结果；文件变化会创建新结果。
# 上传前转写与独立文字归档

桌面端所有网盘上传（自动、手动、历史补传）先尝试本机中文转写，再启动上传。转写失败或模型缺失会记录原因并继续上传，不影响远端确认成功后的本地视频清理设置。暂停或取消上传仍会阻止上传。已生成的文字独立保留；转写失败且视频已删除后，需要从网盘下载视频才能重新转写。

侧栏「转写记录」支持主播名、录制日期和全文关键词组合查询，显示命中片段的时间戳，可查看完整文字、导出 TXT / SRT。文字和任务存放在应用数据目录的 `transcriptions` 中，不随视频清理删除。原视频删除后不可定位播放，但文字查询与导出仍可用。

日期优先读取文件名中的 YYYY-MM-DD，否则使用文件修改日期；跨午夜录制按文件日期归档，分段文件各自保留记录。主播名来自上传任务，手动转写无元数据时使用父目录名。旧版已删除且未转写的视频无法恢复文字。视频清理不依赖转写成功标记，但仍必须满足远端验证和用户的清理设置。
