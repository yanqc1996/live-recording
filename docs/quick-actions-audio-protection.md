# 快捷操作与声音保护

桌面版启动后注册 Command/Ctrl + Shift + K，可从其他应用唤起主窗口及快捷面板。页面也提供常驻入口；面板会显示快捷键是否注册成功（占用时不会抢占其他应用）。搜索主播后可听声音、加入自动录制或打开直播间。加入录制不会关闭其他已启用主播。

macOS 使用随包编译的 CoreAudio 小程序，每 100ms 读取默认输出设备、输出数据源及耳机插孔状态，不申请麦克风权限。任何检测到的输出路由变化都会先将 Electron 主窗口静音，再通知页面暂停音视频和停止直播声音。保护不影响录制，且不会自动恢复声音。页面显示“允许再次播放”，快捷面板的“听声音”也会明确解除静音。

主动切换扬声器也会触发保护。检测存在系统和调度延迟，不能保证零瞬间漏音。非 macOS 平台目前不提供原生检测，面板明确显示不可用；macOS 检测进程异常退出时保守静音。

构建：`node scripts/build_audio_monitor.cjs`。`npm run desktop` 与桌面打包流程都会编译；二进制通过 asarUnpack 发布，无需用户安装编译器。退出应用时清理监听进程与全局快捷键。

验收：播放直播及本地视频，分别拔有线耳机、断开蓝牙耳机、主动切换输出；确认暂停、后台录制继续、重新连接不自动发声。另检查隐藏窗口时快捷键唤起、快捷键占用提示，以及取消面板不改变录制状态。
