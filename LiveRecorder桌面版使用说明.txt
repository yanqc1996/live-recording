LiveRecorder 桌面版使用说明与注意事项
版本：0.1.0
适用平台：macOS Apple Silicon / arm64


一、安装包位置

当前已生成的安装包在项目 dist 目录：

1. LiveRecorder-0.1.0-arm64.dmg
   推荐给普通用户安装使用。

2. LiveRecorder-0.1.0-arm64-mac.zip
   备用压缩包版本，可解压后直接运行 App。


二、macOS 安装流程

1. 双击打开 LiveRecorder-0.1.0-arm64.dmg。
2. 将 LiveRecorder 拖入 Applications（应用程序）目录。
3. 从 Applications 中打开 LiveRecorder。

注意：
当前测试包没有 Apple Developer ID 签名和 notarization，因此 macOS 可能提示：

“无法打开，因为无法验证开发者”
或
“来自身份不明的开发者”

测试阶段可以这样打开：

1. 在 Applications 中找到 LiveRecorder。
2. 右键点击 LiveRecorder。
3. 选择“打开”。
4. 在弹窗中再次点击“打开”。

如果仍无法打开：

1. 打开 系统设置。
2. 进入 隐私与安全性。
3. 找到 LiveRecorder 被阻止的提示。
4. 点击“仍要打开”。

正式对外分发前，建议进行 Apple Developer ID 签名和 notarization，否则普通用户首次打开体验会比较差。


三、首次启动说明

LiveRecorder 是本地桌面应用，启动后会在本机启动一个内置录制引擎。

它只监听本机地址 127.0.0.1，不会开放公网端口。

打包版已经内置：

1. Python 运行时
2. Node.js
3. FFmpeg
4. 百度网盘上传所需的 bypy

用户不需要额外安装 Python、Node.js、FFmpeg 或 bypy。


四、基础录制流程

1. 打开 LiveRecorder。
2. 进入“本地录制”页面。
3. 在“直播间”区域粘贴直播间地址。
4. 点击“添加”。
5. 按需调整录制设置：
   - 保存目录
   - 画质
   - 保存格式
   - 检测间隔
   - 分段录制
   - 是否录完转 MP4
6. 点击“开始本地录制”。
7. 需要停止时，点击“停止并保存”。

录像默认保存在本机 downloads 目录。
如果设置了自定义保存目录，则保存在用户选择的目录中。


五、抖音账号登录

如果只是录制公开可访问的直播间，不一定每次都需要登录。

如果需要更稳定地访问抖音直播相关功能，可以点击“登录抖音”：

1. 点击“登录抖音”。
2. 在弹出的登录窗口中扫码登录。
3. 登录成功后，应用会自动同步录制需要的本机会话。

注意：

1. 不需要手动输入 Cookie。
2. 登录信息保存在 Electron 的隔离会话中。
3. 录制 Cookie 只在本机应用和内置录制引擎之间使用。
4. 如果点击“退出”，会清除本机保存的抖音登录状态。


六、主播库使用流程

主播库用于统一管理主播，而不是每次手动粘贴不同地址。

使用流程：

1. 进入“主播库”。
2. 输入主播名称。
3. 粘贴主播主页、分享链接或直播间地址。
4. 点击“添加主播”。
5. 可以点击“巡检全部”检测主播是否开播。
6. 选择某个主播后，可以：
   - 解析直播间
   - 加入录制
   - 用于互动
   - 拉取作品
   - 删除主播配置

注意：

1. 如果添加的是直播间地址，即使未登录，也会先保存该直播间地址。
2. 如果添加的是主页地址，需要主播正在直播时，才更容易解析到直播间地址。
3. 巡检功能可以手动触发，也可以设置每 1 分钟、5 分钟或 10 分钟自动巡检。


七、直播互动功能

直播互动目前主要用于抖音直播间。

支持：

1. 实时监听弹幕。
2. 查看用户进房、礼物、关注等事件。
3. 尝试发送弹幕。
4. 获取音频源，只听声音。
5. 查看礼物贡献榜。
6. 工作模式：弱化非弹幕信息，适合上班时低调挂着。

注意：

1. 监听弹幕通常依赖登录 Cookie。
2. 发送弹幕还可能依赖抖音网页安全字段。
3. 如果界面提示“发送弹幕可能不可用”，一般不影响监听弹幕。
4. 音频源是否能直接播放，取决于直播源格式和浏览器支持情况。


八、作品拉取功能

作品拉取是一次性任务，不是持续同步任务。

使用流程：

1. 进入“作品拉取”。
2. 粘贴用户主页、分享链接或 sec_user_id。
3. 选择保存目录，也可以留空使用录制保存目录。
4. 点击“开始拉取作品”。

去重逻辑：

1. 应用会记录已处理作品 ID。
2. 默认只拉取上次拉取时间之后的新作品。
3. 如果某个旧作品被用户手动删除，默认不会再次拉回本地。
4. 勾选“强制扫描历史页”会重新扫描历史内容，但仍会跳过已记录作品 ID。


九、媒体库功能

媒体库会按主播聚合本地文件。

可查看：

1. 直播录制文件
2. 作品拉取文件
3. 音频文件
4. 图片文件
5. 每个主播占用空间
6. 最近修改时间

可以选择主播后点击“打开目录”直接查看本地文件。


十、百度网盘上传功能

百度网盘上传是可选功能，默认关闭。

如果不开启，所有录制只保存在本机。

打包版已经内置 bypy，用户不需要安装 Python 或 bypy。

首次使用需要完成一次百度网盘账号授权，因为应用需要知道上传到哪个百度网盘账号。

推荐流程：

1. 打开“本地录制”页面。
2. 找到“百度网盘上传”区域。
3. 勾选“启用上传能力”。
4. 按需设置：
   - 百度网盘远程目录，例如 /apps/LiveRecorder
   - 是否按主播创建网盘目录
   - 是否上传成功后删除本地文件
   - 失败重试次数
5. 点击“保存”。
6. 点击“检测授权”。
7. 如果提示需要授权，按界面输出完成百度网盘授权。
8. 授权完成后，再次点击“检测授权”。
9. 如果检测可用，可以开启“录制完成后自动上传”。

上传队列说明：

1. 录制完成后会进入本地上传队列。
2. 上传失败不会删除本地文件。
3. 失败任务可以在界面中重试。
4. 上传队列保存在本机 config/baidupan_queue.json。
5. 上传设置保存在本机 config/baidupan_upload.json。

重要注意：

1. 不建议默认勾选“上传成功后删除本地文件”。
2. 建议先确认上传成功、网盘文件可播放，再考虑删除本地文件。
3. 百度网盘上传速度和稳定性取决于百度网盘账号、网络环境和接口限制。
4. 百度网盘授权是用户自己的账号授权，不应把授权文件分享给他人。


十一、常见问题

问题 1：macOS 提示无法打开，因为无法验证开发者。

答：
这是因为测试包没有 Apple Developer ID 签名。右键 App，选择“打开”，再确认打开即可。正式发布前建议做签名和 notarization。


问题 2：打开后提示录制引擎启动超时。

答：
可以尝试：

1. 退出应用后重新打开。
2. 确认 App 是否放在 Applications 目录。
3. 检查是否被安全软件拦截。
4. 如果仍失败，保留错误截图和日志。


问题 3：为什么不让用户输入 Cookie？

答：
不建议让普通用户输入 Cookie。桌面版提供扫码登录，登录后自动同步本机会话，体验和安全性都更好。


问题 4：百度网盘上传是否必须开启？

答：
不是。上传功能默认关闭。不开启时，软件就是纯本地录制工具。


问题 5：用户是否需要安装 Python、Node.js、FFmpeg 或 bypy？

答：
打包版不需要。当前安装包已经内置这些运行环境和工具。


问题 6：录制文件在哪里？

答：
默认在应用数据目录下的 downloads 中，或者用户在“录像保存目录”里选择的目录。


问题 7：停止录制后文件损坏怎么办？

答：
建议使用“停止并保存”按钮，不要直接强制退出应用。对于长时间录制，推荐启用分段录制，并使用 TS 格式保存，稳定性更好。


十二、分发前建议

如果准备给非技术用户使用，建议完成以下事项：

1. 配置应用图标。
2. 配置 Apple Developer ID 签名。
3. 做 macOS notarization。
4. 增加首次启动引导页。
5. 增加错误日志导出按钮。
6. 准备一份带截图的图文教程。
7. 明确告知用户：默认只本地保存，百度网盘上传需要用户主动开启并授权。


十三、测试建议

正式发给用户前，建议按以下顺序测试：

1. 安装 DMG。
2. 首次右键打开 App。
3. 添加一个直播间地址。
4. 启动录制。
5. 停止并保存。
6. 打开保存目录确认视频存在。
7. 登录抖音。
8. 测试主播库巡检。
9. 测试直播弹幕监听。
10. 测试作品拉取。
11. 测试百度网盘授权检测。
12. 测试手动上传最近录像。
13. 再开启录制完成后自动上传。
